## Pourquoi une copie, et pas seulement le lien du projet

Le Lab 1 demandait de travailler dans **un dépôt déjà existant** (alternance ou perso) et de le pousser — en pratique, d’envoyer le **lien** de ce repo.

Le projet réel est [SyncMates](https://github.com/UlyssouLV/SyncMates). On a **préféré ne pas y committer** le travail du cours pour l’instant, afin de **laisser ce dépôt intact**.

À la place, une **copie des fichiers** est dans [`SyncMates/`](SyncMates/) (à la racine). Ce n’est plus un Git imbriqué : tout est versionné dans *ce* repo, pour que le prof puisse ouvrir le code sur GitHub (un clone-dans-un-clone n’affichait qu’un dossier gris).

C1 (spec, tickets, context) et C2 (instruction + enforcement) se font donc sur **cette copie**. Le GitHub SyncMates d’origine n’est pas le livrable.
